## التوزيع الحالي

- شعار الشركة: في الوسط العلوي، حول النقطة (505, 420)، داخل مساحة قصوى 510×270.
- عنوان الوظيفة: أسفل الشعار، داخل مساحة تقريباً 760×255 تبدأ من y=665.
- العنوان: حتى 3 أسطر، وحجمه يتغير تلقائياً تقريباً بين 64 و38.
- الخط: Firjar ExtraBold/Bold.
- العربية RTL، والفرنسية/الإنجليزية والمختلط مدعوم.
- اختيار الخلفية عشوائي مع منع تكرار نفس الخلفية مباشرة.

الخلفية نفسها فيها هوية Cybero Plus، لذلك لا يضيف البوت شعار Cybero Plus مرة ثانية؛ يضيف فقط شعار الجهة المشغلة وعنوان الوظيفة.
