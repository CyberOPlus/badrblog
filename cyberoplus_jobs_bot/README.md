# Cybero Plus Jobs Bot

البوت الوحيد المعتمد للتوظيف في Cybero Plus.

المراحل الأساسية:
1. جمع الوظائف من المصادر المعتمدة.
2. Normalization والتحقق من أهلية المغاربة.
3. منع التكرار وتمييز التحديث عن حملة توظيف جديدة.
4. Quality scoring واختيار أفضل فرصة.
5. إنشاء مقال عربي وSEO وJobPosting.
6. Blogger.
7. Facebook + أول تعليق.
8. State دائم وتتبع التحديثات.

السياسة الحالية: الجودة قبل الكمية، ومقال قوي واحد يومياً عادةً، مع استثناء عاجل محدود للفرص الرسمية المؤكدة.
